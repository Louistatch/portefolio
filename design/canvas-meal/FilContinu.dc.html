Une carte efficace fait comprendre la situation instantanément. L'outil : la symbologie graduée, qui colore les objets selon une valeur — rouge pour critique, vert pour correct.

Choisir ses classes

QGIS propose plusieurs modes : intervalles égaux, quantiles, ou des seuils manuels — recommandés pour le MEAL : alignez vos classes sur les seuils de votre bailleur, pas sur la statistique.
